# Новые лиды с сайта франшиз — первое сообщение

Правило Вячеслава (31.10.2026): **первое сообщение новым лидам Claude отправляет сам, без отдельного «да».** Всё остальное (ответы на вопросы, напоминания, договоры) — только после согласования.

## Порядок

1. Проверить лида по таблице «Заявки» (колонка C, телефон). Если нет — добавить строку: дата, имя, телефон, канал, статус «новая», комментарий с текстом заявки, источник «Сайт франшизы», баллы 0.
2. Канал MAX: получить chatId через GREEN-API `checkAccount` (номер без «+»).
   - Если `exist: false` — номера нет в MAX: в комментарии «нужен звонок/SMS/Telegram», сообщить Вячеславу.
3. Отправить два сообщения:
   - `sendMessage`: «{Имя}, Здравствуйте!»
   - `forwardMessages` из чата Басихина `chatIdFrom: 146434153`, **только один id `1793279014343`** — приходит весь альбом из 3 видео с текстом (проверено Вячеславом 31.10). В истории GREEN-API при этом видно одно видео — это нормально, **ничего не досылать**.
4. В таблице: статус «обработана», следующий контакт — завтра 10:00, комментарий «дата первое сообщение (приветствие + альбом). Проверить ответ. chatId …».
5. Telegram и почта: Claude не пишет сам — готовит текст, отправляет Вячеслав (почта — черновик в Gmail).

## Ошибки, которых не повторять

- 29.10: переслали 3 id альбома → лид получил альбом 3 раза. Пересылать **один** id.
- 31.10: по истории решили, что ушло одно видео, начали досылать 2 остальных — не надо.
