# Презентация для дизайнеров и прорабов

Универсальная: технология, изделия, отделка, галерея, порядок заказа. Без станка, цен, окупаемости, условий партнёрства и географии.

Собирается из основной презентации (`materials/presentation/deck.tpl.html`): `mk_partner.py` берёт нужные слайды, меняет тексты, добавляет `partner_last.html` («Как проходит заказ»). Сборка PDF: `node build_partner.js <папка с img/ и gallery/>`.
