# Утеплит — дизайн-система сайта

**Версия:** 3.0 «Графит и красно-оранжевый» — нейтральные серые без синевы, тёмный графит #161616, акцент красно-оранжевый #FE4F31. Собрана поверх 2.0.
**Источник:** артефакт «Утеплит — дизайн-система» (claude.ai/artifact/UPtrMbEpqukn6Ty6EQJyeB).
**Обновлено:** 03.11.2026 (3.1: акцент #FE4F31; фоны только белый #FFFFFF или графит #161616 — серых фонов нет).

> Все значения в компонентах задаются только через токены `--u-*`. Новые HEX в компонентах запрещены.

---

## 1. Принципы

1. **Тепло, а не техника.** Продаём тепло и тишину в доме. Мягкие формы, крупные скругления, фото реальных квартир.
2. **Одно действие — один цвет.** Главная кнопка красно-оранжевая, одна на экран. Остальное — серые поверхности и графит.
3. **Ритм светлое / тёмное.** Секции чередуются: светло-серый фон → белый → графит. Графитовая секция 1–2 раза на страницу: шаги и финал.
4. **Фото — доказательство.** Только реальные объекты с подписью. Поверх фото — маленькие карточки с фактом, а не декор.

### 2.3. Правила цвета

- На тёмных секциях главная кнопка **белая** с текстом `--u-ink`.
- «Тёмная» кнопка внутри карточки — белая с контуром 1.5px `--u-ink`; при наведении заливается `--u-ink`.
- Цена и итог в таблице — цвет `--u-ink`, жирный 700.
- Системная тёмная тема браузера **не меняет** бренд: тема одна.
- Смысл всегда написан словами; цвет только поддерживает.

### 2.4. Пропорция на странице (ориентир)

Светлый фон ~55% · белый ~20% · графит ~15% · выделенный серый ~5% · кнопки ~3% · синий ~2%.

## 3. Типографика

**Гарнитура:** Onest (Google Fonts, кириллица), запасные — `system-ui, -apple-system, sans-serif`.
**Начертания:** 400 текст · 500 навигация и чипы · 600 заголовки, цены, кнопки · 700 метки, логотип, заголовки карточек.
**Регистр:** заголовки — обычный регистр с плотным трекингом. **Капс запрещён** в заголовках и кнопках (только eyebrow и теги).

|---|---|---|---|

| `--u-fs-h2` | clamp(30px, 4vw, 48px) | 600 / 1.08 / −0.03em, max 18ch | Заголовок секции |
| `--u-fs-h3` | 20px (24px в featured) | 600–700 / 1.25 / −0.01em | Заголовок карточки |
| `--u-fs-num` | clamp(44px, 5vw, 64px); 36px на мобильном | 600 / 1 / −0.03em | Цифры шагов, цены |
| lead | 17px | 400 / 1.6, max 52ch | Вводный абзац |

Правила:
- Прописные подписи — не меньше 11–12 px.

- Цифры в таблицах — `font-variant-numeric: tabular-nums`.

## 4. Отступы

Шкала на 4/8. Внутри компонента — мелкие шаги, между блоками — крупные. **Заголовок всегда ближе к своему тексту, чем к следующему блоку.**

| Токен | px | Типичное применение |
|---|---|---|
| `--u-s1` | 4 | иконка ↔ подпись, промежуток табов |
| `--u-s2` | 8 | между пунктами, вокруг фото |
| `--u-s3` | 12 | между кнопками, пункты списка |
| `--u-s4` | 16 | gap сетки карточек, eyebrow → H2, H2 → lead |
| `--u-s5` | 20 | H1 → lead, внутреннее поле на мобильном |
| `--u-s6` | 24 | поле тарифа и шага, внутреннее поле на десктопе |
| `--u-s8` | 32 | lead → кнопки, шапка секции → сетка (мобильный) |
| `--u-s10` | 40 | шапка секции → сетка (десктоп) |
| `--u-s12` | 48 | колонки «фото + текст» |
| `--u-s16` | 64 | секция на мобильном |
| `--u-s24` | 96 | секция на десктопе (≥1024) |

| Связка | Отступ |
|---|---|
| Секция сверху/снизу | 64 → 96 (≥1024) |
| Eyebrow → H2 | 16 |
| H2 → lead | 16 |
| Шапка секции → контент | 32 (мобильный) → 40 (≥768) |
| H1 → lead → кнопки | 20 → 32 |
| Между карточками | 16 |
| Внутреннее поле (`--u-inset`) | 20 (мобильный) → 24 (≥768) |
| Поля контейнера | 16 → 32 (≥768) |

| `--u-r-field` | 14px | Поля ввода, плавающие карточки |

Тени:
- `--u-shadow-soft: 0 1px 2px rgba(14,14,14,.04), 0 10px 30px rgba(14,14,14,.06)` — белые карточки на сером фоне (без обводки).
- На белой секции карточки — **без тени**, с линией 1px `--u-line`.
- `--u-shadow-float: 0 8px 24px rgba(14,14,14,.12)` — только элементы поверх фото.
- Featured-карточки и тарифы — без тени.

## 6. Сетка и адаптив

- Контейнер: max 1200px + поля. Поля 16px → 32px с 768px; учитываются `safe-area-inset`.
- Шапка: 60px на мобильном, 72px на десктопе; липкая, прячется при скролле вниз.

| Ширина | Правило |
|---|---|
| до 639 | 1 колонка; поля 16; кнопки первого экрана на всю ширину; фото героя под текстом |
| 640–1023 | карточки по 2; featured на всю ширину; шаги 2×2; поля 32 с 768 |
| 1024+ | навигация и телефон в шапке; бенто в 3 колонки (featured — 2); шаги в 4; секции 96 |
| 960+ | первый экран и блок «почему» — 2 колонки |

Мобильный слой:
- Однотипные карточки на мобильном листаются вбок (карусель, карточка 84% ширины, snap).
- Лента доверия — одна строка с горизонтальной прокруткой.
- Внизу экрана — липкая кнопка (после первого экрана, до финала), не таб-бар.
- Диалог — нижний лист на всю ширину.
- На мобильном всё выравнивается по левому краю, даже «центральные» секции.
- Цель нажатия ≥ 44px; основная кнопка 52px.

## 7. Компоненты

### Кнопки
- Pill, высота 52px (малая 44px), поля 24px, текст 600 15px, стрелка →.
- **Primary** — синий `--u-action`, белый текст. Одна на экран.
- **Outline** — контур 1.5px `--u-ink`, прозрачная; при наведении заливается.
- **Dark (в карточке)** — белая с контуром, при наведении графит.
- Кружок-стрелка 36px — переход из карточки.
- Нажатие: `scale(.98)`; переходы 0.12–0.18s; при `prefers-reduced-motion` анимации отключаются.

### Метки, чипы, иконки
- **Eyebrow** — над каждым H2 секции: pill, 12px, 700, капс, подложка `--u-coral-soft`.
- **Tag** — внутри карточки: белый на выделенной, синий на тёмной.
- **Chip** — факт-доверие над H1, белый с линией, 13px.
- **Иконка** — квадрат 36, радиус 10, контурные SVG 18px, stroke 2.

### Плавающие элементы на фото
- Не больше **трёх** на одном фото; выступают за край на 8–12px.
- Белая — факт/время; тёмная — гарантия/качество; синий круг 88px (наклон −8°) — цена «от»; синая плашка — статистика.
- Аватар-кружок 96px с белой обводкой 5px — в углу фото блока «почему».

### Панель проверки города
- Десктоп — pill в одну строку: 3 поля + кнопка. Мобильный — карточка.
- Поле: иконка + подпись 11px + значение 600 (16px на мобильном, чтобы iOS не зумил), разделители 1px. Вся строка — зона нажатия 52px.

### Лента доверия
- Сразу после первого экрана, тёмный фон, 600 14px, разделитель «+» цвета синего, 3–5 коротких фактов.

### Карточки
- **Услуга:** белая, радиус 20, фото в край (скругляет карточка), тело с полем `--u-inset`. Порядок: мета · цена → заголовок → текст.
- **Featured-услуга:** выделенный серый `--u-peach`, фото слева, 2 колонки, одна на ряд.
- **Тариф:** название → описание → крупная цена → список с галочками. Выделенный тариф — графит, галочки синие.

### Шаги
- Только на тёмной секции. 4 карточки с номером 01–04 цвета синего, линия 1px `--u-line-dark`, радиус 20, поле 24.

### Табы, строки-факты, FAQ
- **Табы-сегменты:** белая pill-подложка, активный — `--u-ink` с белым текстом, высота 44.
- **Строки-факты** (пример объекта): `dt` приглушённым, `dd` жирным справа, итог 700.
- **FAQ:** белые карточки радиус 20, вопрос — полноценная фраза 16px 600, ответ 15px приглушённым, до 65 знаков; «+» в кружке 28px.

### Галерея
- Плитки радиус 20, высокие на 2 ряда (десктоп). На мобильном — ровные 3:4, последняя нечётная — 16:9.
- Подпись — белая pill слева внизу: «До / Процесс / После · что видно».
- Иллюстрация, а не реальное фото, — метка «иллюстрация» (11px) в углу.

### Поля и диалог
- Поле: высота 48, радиус 14, линия 1px, фон `--u-bg`, текст 16px.
- Диалог: радиус 28, ширина до 520, поле 32; затемнение `rgba(14,14,14,.55)`; кнопка закрытия 40px круглая.
- Фокус: обводка 3px `--u-focus`, отступ 3px.

## 9. Делаем / не делаем

**Делаем**
- Одна главная кнопка на экран.
- Чередуем светлый / белый / графит.
- Цены — «от» и «за метр» рядом с цифрой.
- Фото только реальных объектов с подписью; иллюстрации помечаем.
- Неразрывный пробел в «450 000 ₽», «53 кг».
- Цель нажатия ≥ 44px.

**Не делаем**
- Капс в заголовках и кнопках.
- Тени у обычных карточек на белой секции.
- Две тёмные секции подряд.
- Таймеры, «осталось 2 места», выдуманные скидки.
- Больше трёх плавающих элементов на фото.
- Новые HEX в компонентах.

## 10. Голос и контент

- **Обычный язык:** «Тепло, тихо, красиво», «первый дом — вместе». Без «уникальной возможности».
- **Глаголы в кнопках:** «Проверить мой город», «Смотреть цены», «Обсудить запуск».
- **Петля ожиданий:** вера (кто за станком) → предвкушение (что будет после заявки) → ощущение → подтверждение (приезжайте на объект).
- **Цифры — только согласованные:** 450 000 ₽ без НДС; 100 пог. м за смену; пример объекта Москва 120 м (593 000 / 69 000 / 60 000 / 464 000 ₽) — всегда с оговоркой про налоги и что это крупный объект.
- **Запуск — только через покупку станка.** Не предлагать старт «без станка» или с готовыми изделиями по дилерской цене.
- **Не обещаем:** гарантию дохода, эксклюзив на город, сроки окупаемости в месяцах. Не публикуем выдуманные отзывы.
- **Требуют сверки с Сергеем до публикации:** вес станка (40 / 53 кг), число станков по России («40 станков» в примере чипа), «разработчик с 1994 года» и «поддержка 24/7» в примере ленты, срок гарантии, НДС, оплата частями, список городов.

## 11. Проверка перед внедрением

- Ширины 320, 390, 430, 768, 1024, 1440 px; увеличение до 200%.
- Длинные заголовки, большие суммы, переносы цены и текста в таблицах.
- Клавиатура: Tab, Enter, Space, Escape; возврат фокуса после диалога.
- Состояния: наведение, нажатие, фокус, загрузка, ошибка, недоступно, отказ буфера обмена.
- Контраст текста ≥ 4.5:1 (крупного ≥ 3:1).
- Без JavaScript содержание читается; шрифт имеет системный запасной вариант.

## Приложение B. Длинные тексты (лонгрид)

Для лонгридов и статей — упрощённая журнальная вёрстка (см. `uteplit-longread-journal.html`):
- Сетка 12 колонок, промежуток 24px (16px на мобильном); блоки по 3, 4, 6 или 12 колонок.
- Каждый блок: линия сверху → подпись → заголовок → текст; верх соседних колонок на одной линии.
- В одном ряду — блоки одного типа (с линией или с заливкой).
- Картинка — на всю ширину или в паре с текстом; в ряду одна пропорция (4:3, широкая 21:9).
- Ритм: раздел → раздел 96, заголовок раздела → контент 48, ряд → ряд 48.
