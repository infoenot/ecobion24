# Презентация для собственников (конечный клиент)

9 страниц: обложка с фото, знакомая ситуация, 7 задач (порядок как в буклете), как делаем, что ещё можно сделать, отделка, 2 страницы фото, как заказать + телефон.
Без станка, цен, схем и технических подробностей. Цвета: светло-яркий синий #1A9BFC + нейтральный тёмный графит #262626 (как у презентации для партнёров).
Сборка: `python3 mk_client.py` (из основной презентации), затем `node build_client.js <папка pres>`; фото берутся из `booklet/hi`, `img`, `gallery`.
