# Инфостиль для текстов «Утеплит»

Источник: М. Ильяхов, Л. Сарычева, «Пиши, сокращай» (2016). Изучены вступление, «Что в голове у хорошего автора» и глава 1 до «Оценок и усилителей» включительно; остальные правила — общие принципы инфостиля.

## Главное

1. **Забота о читателе.** Перед текстом ответить: какую задачу читателя он решает? Пишем с точки зрения его задач (мастер хочет понять, что покупает, сколько заработает, как запустится), а не наших («продать станок»).
2. **Смысл важнее формы.** Нет волшебных продающих слов. Если нечего сказать — инфостиль не спасёт: сначала собрать факты.
3. **Правда, даже неудобная.** Честно о рисках, ограничениях, сроках. Никаких гарантий дохода, «маржи 500 %», фейкового дефицита.
4. **Кратко, ясно, убедительно.** Если мысль можно выразить проще — выражаем проще. Даже для эксперта.

## Метод: увидеть → удалить → наполнить

1. Найти стоп-слова (список ниже).
2. Удалить, не вредя смыслу.
3. **Наполнить фактами.** Без этого шага текст пересушен. Убрали «качественный» — добавили «лист ПВХ 10 мм, шов термосварной».

Упрощать по уровням: слова → предложения (синтаксис) → смысл (повторы, лишнее) → порядок изложения → подача (заголовки, абзацы, выделения).

## Стоп-слова

**Вводные** — удалить: «как известно», «не секрет», «на мой взгляд» (только при противопоставлении чужому мнению), «честно говоря», «точнее/вернее» (скажи сразу точно), «во-первых/во-вторых» (вместо них — абзацы; цифры только для шагов инструкции или пунктов, на которые ссылаются), «например» (часто заменяется двоеточием), «кстати», «конечно», «разумеется», «в общем», «по сути», «итак», «таким образом». Скобки — либо убрать, либо вынести в текст. Лакейская вежливость («будьте так добры, если несложно, заранее спасибо») → забота на деле: объяснить зачем, приложить нужное, предложить помощь.

**Оценки** — заменить фактами, которые читатель поймёт и оценит сам: качественный, надёжный, эффективный, уникальный, инновационный, современный, профессиональный, выгодный, быстрый, удобный, простой, лучший, идеальный, высокий, огромный, премиальный, надёжный, безупречный, гарантированный, стабильный и т. д.
- «Быстрый монтаж» → «короб на окно 3 м — за N часов».
- «Высокая маржа» → «материал на объект X ₽, клиент платит Y ₽».
- «Профессиональное обучение» → «2 дня на нашем объекте в Москве + год консультаций».

**Усилители** — удалить всегда: очень, максимально, абсолютно, действительно, совершенно, невероятно, самый, именно, всего лишь, полностью, настоящий («настоящие профессионалы» → факт о людях), безусловно, несомненно, крайне, весьма.

**Вместо оценок — истории и сценарии.** Не «уютно и тепло», а «зимой стойка не покрывается инеем, у окна можно поставить стол». Описывать ситуацию, где продукт полезен.

Прочие группы (общие правила инфостиля): штампы и канцелярит («осуществляет деятельность», «является», «в рамках», «на сегодняшний день», «динамично развивающаяся»), заумь и иностранщина без нужды, эвфемизмы (говорить прямо: «цена выросла», а не «произошла корректировка»), отглагольные существительные («осуществление монтажа» → «монтируем»), страдательный залог («производится нами» → «делаем»), неопределённость («ряд», «некоторые», «различные», «определённый») → число или конкретика, брехня (непроверяемые «лидер рынка», «№1»).

## Структура и подача

- **Пользу — вперёд.** Сначала главное для читателя, потом детали.
- **От простого к сложному.**
- **Один абзац — одна мысль.** Короткие абзацы, 2–4 предложения.
- **Заголовок** говорит суть раздела, а не тему: не «Оборудование», а «Что входит в комплект».
- **Списки** — для однородных пунктов; нумерация — только для шагов.
- **Числа цифрами**, единицы измерения, сроки, цены.
- **Примеры** вместо абстракций.
- **Проверка вслух:** не хватило дыхания или запутался в интонации — делить предложение.

## Чек-лист перед выдачей

- [ ] Ясна задача читателя, текст её решает.
- [ ] Нет вводных, оценок, усилителей, штампов (прогнать по спискам).
- [ ] Каждое утверждение подкреплено фактом/числом или убрано.
- [ ] Нет обещаний дохода, неподтверждённых цифр, фейкового дефицита.
- [ ] Заголовки разделов — суть, а не тема.
- [ ] Абзацы короткие, одна мысль; нумерация только где нужна.
- [ ] Прочитано вслух.
